## 三种"原生"口径，卖家说的可能不是一回事

"原生 IP"在中文 VPS 圈没有统一标准，至少有三套说法在并行使用。

**口径一（严格）**：IP 在归属数据库里登记的是目标国家的真实 ISP 或住宅网络，不是数据中心段。平台的检测系统看到这个 IP，识别出的是"某地普通宽带用户"，不是"某云服务商机房"。

**口径二（宽松）**：IP 的注册地址和 VPS 所在国家一致就算原生。机房在洛杉矶、IP 归属显示美国，过关；机房在洛杉矶、IP 注册在某个云厂商名下，叫广播 IP。

**口径三（ASN 归属）**：IP 的 ASN 归属是当地 ISP 运营商，IP 数据库里查出来的标签是 Residential，或者至少是本地商业宽带。

问题出在口径二。按它的标准，大量机房 IP 都能叫原生，因为云厂商的 IP 段本来就注册在机房所在地。真正影响你账号死活的，是口径一和口径三说的那件事：这个 IP 的 ASN 挂在哪。

平台的检测逻辑大致是这样：TikTok、Instagram 这类看 ISP 属性和住宅标签，云厂商的 ASN 容易被识别成"机器号"；Netflix、Disney+ 看 ASN 归属和地区库，机房段大概率被判为代理而锁区；ChatGPT、Claude、Gemini 对纯净度敏感，数据中心 IP 容易触发风控，不过对住宅属性的要求比前两类低一些。

## 下单前必须问清的五件事

**1. 退款退到哪里、期限多久**

官网在 AS9929 住宅版上明确写了"退款仅退网站余额"。这句话的意思是你付的现金变成了站内额度，取不出来。其他套餐的退款期限，套餐页没有直接列出。

行业里的差异有多大，看两个真实例子：一家做德国双 ISP 住宅的服务商给 48 小时无条件全额退款、原路退回，但特价年付产品和部分特殊产品（比如美国家庭宽带 VDS）只退余额；另一家马来西亚服务商的政策是，只有购买后 24 小时内发现 IP 不可用才能换 IP，超时不换。$260 不是小数目，这两条先发工单问明白再付款。

**2. 换 IP 的政策**

住宅 IP 被封或被平台标记之后能不能换、多久能换一次、收不收费，官网套餐页没有公开说明。IP 是这类产品里最贵的部分，这条政策比 CPU 型号重要得多。

有些商家在这方面给得比较松，比如有服务商对 IP 被墙的情况每 15 天可免费换一次，其他情况收 $5/次。也有商家卡得很死。SixtyNet 属于哪一种，只有问客服才知道。

**3. 80 和 443 端口**

住宅系列全系不开这两个端口。这不是配置问题，是商家主动关的，工单也开不出来。如果你的用途里有一项是"顺便挂个网站"，那这台机器做不到。

**4. 能不能装 Windows**

官网套餐页没有标注各套餐的系统支持情况。别默认可以，也别默认不行。要装 Windows 就发工单问清楚，顺便问内存够不够，2G 跑 Windows Server 本身就很紧张。

**5. 续费是不是同价**

年付 $260 是折后价，标价 $300。第二年续费按哪个价格算，官网没有明说。这类产品常见的做法是首年折扣、续费回原价，差价一年 $40，长期用要算进去。

## 常见问题

**Q：住宅 IP 套餐能建站吗？**

不能。官方明确不开放 80 和 443 端口，原因是 IP 风控。要建站选 LAX 系列。

**Q：原生 IP 和双 ISP 到底差在哪？**

原生说的是 IP 归属在当地 ISP 名下；双 ISP 说的是 `company` 和 `asn` 两个字段的类型都是 ISP，不是 hosting 也不是 cloud。双 ISP 是更严的那一档，在 TikTok 这类平台上更像真实家庭用户。SixtyNet 两种都卖，双 ISP 需要额外付费。

**Q：做 TikTok 美区，选 SixtyNet 哪一档？**

Residential-STARTER，$260/年。下单前跟客服确认上游是 Cox Communications 还是 Astound Broadband，以及是不是双 ISP 版本。这两项决定了平台的判定结果，配置高低不决定。

**Q：年付还是月付？**

官网在部分套餐上同时给了季付和年付折扣，年付省得最多，住宅系列年付比标价低 13% 到 16%。但年付意味着一次性付 $260 以上，退款条款一定要先确认。不确定用途对不对，先按月付跑一轮，验完 IP 属性再转年付。

**Q：AS9929 优化版和普通住宅版差在哪？**

多一条中国方向的路由优化，回国的链路质量更好。代价是限制更严：拒绝所有外部探测与扫描，只有白名单设备或端口转发能连进去，退款只退网站余额。如果你不是对国内访问延迟有硬要求，普通住宅版够用。
